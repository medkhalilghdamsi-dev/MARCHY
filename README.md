# MARCHY Marketplace

A responsive, multi-page marketplace frontend built with React and Vite.

## Run locally
```bash
npm install
npm run dev
```

## Current frontend
- Marketplace homepage and category discovery
- Product grid with search, category and price filters
- Sorting by featured, price and rating
- Product detail pages
- Client-side cart and quantity controls
- Wishlist toggles
- Responsive navigation and mobile layouts
- Seller and account placeholder pages

## Important
This is a frontend prototype using sample product data and remote demo images. Cart and wishlist state currently live in memory and reset on refresh. Authentication, checkout processing, inventory, seller management, real product data, delivery calculations and backend integrations are not connected yet.
